ESTÚDIO CRIATIVO · WALDÊNIA SILVA

Política de Privacidade

Última atualização: 15 de outubro de 2026.

1. Responsável pelo tratamento

Waldênia Silva, através do Estúdio Criativo, é responsável pelo tratamento dos dados pessoais enviados voluntariamente através dos formulários deste site. Para questões relacionadas com privacidade, pode contactar: janine.consultor@outlook.pt.

2. Que dados podem ser recolhidos

Consoante o formulário preenchido, podem ser recolhidos o nome, endereço de e-mail, número de telefone, informação sobre a marca ou projeto, preferências, prazos, orçamento, mensagens e ficheiros anexados pelo próprio utilizador. Não envie dados pessoais desnecessários ou informações sensíveis.

3. Finalidades e fundamento

Os dados são utilizados para analisar e responder a pedidos de contacto, compreender os requisitos de um projeto, preparar propostas e comunicar com a pessoa interessada. Quando o pedido evolui para uma relação contratual, os dados estritamente necessários podem também ser tratados para diligências pré-contratuais ou execução do contrato. Nos restantes casos, o tratamento baseia-se no pedido voluntário de contacto e, quando aplicável, no consentimento.

4. Como são enviados os dados

Os formulários utilizam o serviço FormSubmit para encaminhar as mensagens para o endereço de e-mail indicado. O fornecedor poderá tratar dados técnicos e os dados submetidos para prestar o serviço, de acordo com as suas próprias condições e política de privacidade. Este site está alojado no GitHub Pages; a visita ao site pode envolver o registo de dados técnicos, como o endereço IP, para fins de segurança, segundo as práticas do fornecedor de alojamento.

5. Conservação e partilha

Os dados são conservados apenas durante o período necessário para responder ao pedido e acompanhar eventual relação profissional, sem prejuízo de obrigações legais aplicáveis. Não são vendidos. Só serão partilhados com prestadores técnicos envolvidos no funcionamento do site ou quando tal seja necessário ou legalmente exigido. Os serviços externos podem tratar dados segundo as suas próprias políticas.

6. Direitos da pessoa titular dos dados

Nos termos da legislação aplicável, incluindo o RGPD quando aplicável, pode solicitar acesso, retificação, apagamento, limitação ou oposição ao tratamento, bem como exercer o direito à portabilidade quando aplicável. Para o efeito, contacte janine.consultor@outlook.pt. Pode ainda apresentar reclamação à Comissão Nacional de Proteção de Dados.

7. Segurança

São adotadas medidas razoáveis para limitar o acesso aos dados recebidos. No entanto, nenhum método de transmissão ou armazenamento eletrónico garante segurança absoluta. Evite enviar informações confidenciais através dos formulários.

8. Alterações a esta política

Esta política poderá ser atualizada para refletir alterações aos formulários, aos serviços utilizados ou às obrigações legais. A versão publicada nesta página é a versão em vigor.
